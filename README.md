# Tutor Support System

A comprehensive web-based platform designed to facilitate and manage tutoring activities, student support, and academic resource sharing.

## Introduction
The **Tutor Support System** is built to bridge the gap between students seeking help and tutors ready to provide guidance. It features a robust session management system, a digital library for academic materials, and a custom-built CAS (Central Authentication Service) simulation for secure login.

## Key Features

### For Students
- **Dashboard**: View upcoming tutoring sessions and personal progress.
- **Session Enrollment**: Browse available sessions by subject, tutor, or schedule and enroll with one click.
- **Session Management**: Reschedule or cancel enrollments as needed.
- **Library Access**: Access study materials, research papers, and lecture notes.
- **Feedback**: Provide feedback on sessions and report technical issues.

### For Tutors
- **Schedule Management**: Set and update weekly availability for tutoring.
- **Session Operations**: Manage student enrollments, reschedule classes, or cancel sessions with automatic student notifications.
- **Student Monitoring**: Track student progress and attendance across different subjects.
